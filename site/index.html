The failure

Three ways an agent lies without lying

It edits the file, runs nothing, and reports success. It patches the symptom because it never located the invariant. It accepts a subagent's summary as proof that a deploy happened.

None of these are model intelligence problems. They are proof problems: the agent was allowed to end its turn without naming evidence.

Rules help. Rules that fail a build when the evidence is missing work better.

scripts/check.sh
$ ./scripts/check.sh
FAIL: skills/plan/SKILL.md declares
      name '', dir is 'plan'
FAIL: examples/debugging-closeout.md
      missing closeout label 'blocked'
FAIL: found email address
exit=1

$ ./scripts/check.sh
OK: checks passed

Install

Four layers, stop where it is enough

  1. Paste the rules block into your agent. Five minutes, no install.
  2. Drop an AGENTS.md into the repo so the rules travel with the code.
  3. Install a preset with one command. Ten skills, not a hundred.
  4. Adopt the runtime settings and operator template once the basics hold.
install
git clone https://github.com/Urdemonlord/hermes-rules-kit
cd hermes-rules-kit

./scripts/install-skills.sh default --dry-run
./scripts/install-skills.sh default

# second run copies nothing, by design

Works on any agent that reads SKILL.md. Claude Code and Cursor need tool names mapped first; that is documented, not hidden.

Limits

What this does not do

No benchmark claims. There is no study showing this cuts your failure rate by a fixed percentage, and I am not going to invent one.

It does not make an agent correct. It makes an unproven claim visible, which is a smaller promise and the one that holds.

Isn't this free on GitHub?

Yes. MIT, public, and it stays that way. The pack is the selected subset, the configuration for a stack, and updates when the skill set changes. If you would rather clone it and wire it yourself, do that.

Do I need Hermes?

The rules are agent-agnostic. The skills name Hermes tools, so Claude Code and Cursor users map the tool names first. The mapping is in the repo.

How old is this?

Four months of real work from one operator, not a course. Small, opinionated, and edited when something breaks.
