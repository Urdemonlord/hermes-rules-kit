# Map-first positioning for listing/directory web apps

Use this when a listings product is competing with an incumbent marketplace but does not own the full transaction.

## Core heuristic
If the product's defensible value is discovery by geography, make the map the first-screen artifact. Do not hide it behind a generic marketing hero.

## When this applies
- Listings are location-sensitive (kos, rentals, hotels, services, POIs)
- The incumbent is stronger at transaction/completeness than at browsing UX
- Your product adds value mainly through exploration, comparison, or visual clustering
- Exact owner contact is incomplete, uncertain, or controlled by the source marketplace

## Positioning pattern
Frame the product as:
- discovery layer first
- source marketplace second
- transaction engine not owned here

Example framing:
- "Open the map, choose the area, compare quickly, continue to the source"
- Avoid implying direct booking/contact flows if the data source does not support them reliably.

## Homepage pattern
1. Lead with a map-first hero, not a text-only hero.
2. Put floating search + quick area chips over the map.
3. Show the product category in one line: e.g. "Peta kos Semarang".
4. Make the CTA open map mode directly.
5. Add a short explanation of why the map helps: area understanding, faster comparison, less blind scrolling.

## Data integrity rules
- Never show fake owner phone/email placeholders.
- If source branding is visible in the listing assets and owner contact is uncertain, prefer an explicit "View on source marketplace" CTA.
- If third-party contacts exist but property matching is weak, treat them as unverified and do not expose them as primary UX.

## Mapping rules
- Map-first only works if pins are spatially meaningful.
- If exact coordinates are unavailable, use area/district centroid coordinates as an interim step.
- Do not place every listing on the same city-center coordinate; it destroys the product's positioning promise.
- Fetch enough listings for the homepage/search map to feel representative of the market, not just a teaser subset.

## Copy guidance
Prefer:
- "Cari kos lewat peta"
- "Bandingkan per area"
- "Lanjut ke sumber asli"

Avoid:
- overclaiming direct transactions
- generic trust/booking copy copied from marketplace apps
- pretending to be a full-stack booking platform when the real value is discovery
