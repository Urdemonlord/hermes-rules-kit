# v0.2.1 — Skill library, operator template, repo self-check

## Added

- **Skill library.** 94 field-tested skills alongside the 10 framework skills, indexed in `skills/INDEX.md`: DevOps and VPS operations, software delivery (SvelteKit, Next.js, Android/Kotlin, payments), security assessment and APK work, research, classifier evaluation, media, GitHub workflows.
- **`templates/AGENTS.operator.template.md`** — the operator-level law: identity block as placeholders, engineering discipline unchanged.
- **`config/hermes-settings.md`** — sanitized runtime settings that actually change execution behavior, with the reasoning for each value.
- **`scripts/check.sh`** — repo self-check. Fails on: skill frontmatter name mismatch, missing closeout label, broken relative `.md` link, README version drift, dangling `references/` link, email address, local home path, API token, inline credential, or non-public IP literal.

## Changed

- Closeout shape unified across template, examples, and the coding skill: `changed`, `verified`, `unverified`, `blocked`, `assumption`, then files touched.
- `docs/core-runtime-law.md` named as canonical. Template, paste block, and coding skill carry a header saying the core law wins on disagreement.
- `skills/README.md` and `docs/architecture.md`: "mirror" replaced with an explicit direction-of-truth rule. The private runtime copy is authoritative for behavior; this repo publishes portable rule text only.
- README release section no longer contradicts the badge.

## Sanitization

Every published skill was scanned and rewritten before landing: email addresses replaced with `user@example.com`, public IPs with `203.0.113.10`, operator home paths with `/home/user`, credential assignments redacted, brand and project names generalised to roles ("the storefront", "the gateway", "the brand site"). `check.sh` enforces the same scan on future changes.

## Excluded on purpose

Vendored third-party packs, operator-personal skills (vault bridge, working-style notes, maintenance runbooks), and skills byte-identical to the upstream Hermes distribution. See `skills/README.md`.
